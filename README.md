# 🍔 Codify Food Court

> *Enjoy healthy and delicious food.*

A landing page for a fictional restaurant, built with **HTML and CSS only**. I made it to practice layout and styling. It's not a working store.

**🔗 Live demo:** [m7md132-star.github.io/food-store](https://m7md132-star.github.io/food-store/)

---

## ✨ Features

- **Navigation bar** with the logo, links (Home, Menu, About us, Reservation, Blog) and user, search and shopping bag icons
- **Hero section** with a welcome title and **Order now** and **Reservation** buttons
- **Opening hours** box
- **Burger image** next to links for Facebook, WhatsApp and Instagram
- **Hover effects** on the nav links and buttons
- **Soft background** made from layered radial gradients in green and cream

## 🤖 Use of AI

I built this project to learn, so I wrote the HTML and CSS myself. I used AI (Claude by Anthropic) as a helper, not to write the site for me.

**What AI helped with:**

- **Writing this README:** AI drafted it from the project's code, and I reviewed and edited it.
- **Reviewing my code:** AI pointed out small CSS mistakes, like an invalid `border-radius` value.
- **Explaining concepts:** when I got stuck, I asked AI to explain how something works instead of giving me the answer.
- **Deploying to GitHub Pages:** AI helped me figure out why my sites weren't loading and how to fix the folder structure.

**What I did myself:**

- Designed the page layout and chose the colors and fonts
- Wrote the HTML structure and the CSS styles
- Picked and prepared the images and icons
- Tested the page in the browser and fixed issues

## 🚀 Run it locally

No install or build step is needed.

1. Clone the repo:
   ```bash
   git clone https://github.com/m7md132-star/food-store.git
   ```
2. Open `index.html` in your browser.
